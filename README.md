## 🛫 Overview
AviCore produces custom aviation simulation controls, 3D cockpit panels, avionics bezels, soft gauges, and custom airport scenery for Microsoft Flight Simulator (MSFS), Prepar3D, X-Plane, and DCS World.

## 💻 Local Development
To serve locally with Apache / XAMPP:
1. Clone or place this folder in your web root (e.g., `C:\xampp\htdocs\avicore`).
2. Start Apache from the XAMPP Control Panel.
3. Access via browser at `http://localhost/avicore/`.
