Configuration checklist

Start with the details that change the build.

The more specific the brief, the faster the design review. If you are unsure about a field, say so and the team will help define it.

  • Screen size and resolution
  • Instrument set
  • Data source and simulator
  • Theme and colour
  • Touch / non-touch workflow
